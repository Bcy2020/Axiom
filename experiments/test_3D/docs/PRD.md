**考题名称**：3D建模工具构建

**核心目标**：
构建一个**图形界面交互式**的3D建模工具。该工具需支持从2D草图绘制、2D区域自动分割，到3D实体生成（拉伸/扫描/旋转）、实体编辑（布尔/抽壳/合并）以及完整的视口交互（视角控制、Gizmo变换）。

**技术栈与平台政策（完全开放）**：
- **编程语言**：不限（任何语言皆可）。
- **图形/渲染方案**：不限（OpenGL、DirectX、Vulkan、WebGL、纯软件渲染等皆可）。
- **GUI框架**：不限（Qt、WPF、WinForms、Flutter、Electron、原生Web、终端TUI等皆可）。
- **辅助库**：允许适当选用外部库辅助实现**非核心业务逻辑**（如数学计算、几何相交判定、UI组件等）。**严禁使用任何提供完整B-rep建模能力或一键式3D编辑器全流程的现成SDK**。
- **打包与交付形式**：不限（解释型脚本直接运行、编译型二进制可执行文件、安装包、网页链接等皆可，只要能运行并演示即可）。

**数据持久化要求**：
- 必须支持将当前场景中的全部模型数据**导出**为某种格式的文件（格式不限，可自创），并支持将此文件**重新导入**恢复完整场景。
- 导出的数据应包含：几何信息、材质信息、变换信息（位置/旋转/缩放）、分组/层级关系。


#### 一、交互与视口基础
1. **主绘图区/3D视口**：占据界面最大面积，包含**自适应网格**，并实现**网格吸附**功能。
2. **视角控制**：
   - 鼠标右键拖拽（或对应交互方式）：旋转三维场景视角。
   - 鼠标中键拖拽（或对应交互方式）：平移场景视角。
   - 提供显式按钮，点击后相机切换为**俯视正交投影**。在此模式下，所有绘制的2D图形默认落于 `Z=0` 平面。
3. **2D/3D融合**：不设独立2D界面区。俯视正交视角即"草图模式"，退出俯视视角即为"3D观察/编辑模式"。

#### 二、2D草图工具集（含参数化输入）
所有2D工具必须提供**鼠标拖拽绘制**和**面板参数输入**两种触发方式。绘制的线条需自动参与**闭合区域拓扑计算**（见第五条）。

- **线段**：自由（两点）；参数（起点坐标 + 长度）。
- **圆形**：自由（圆心 + 圆上点）；参数（圆心坐标 + 半径）。
- **贝塞尔曲线**：多点确定（**仅自由绘制，不提供参数化**）。
- **正多边形**：自由（一条边 + 边数）；参数（中心点 + 边长 + 边数）。
- **椭圆**：自由（两个焦点 + 椭圆上一点）；参数（两个焦点坐标 + 离心率）。

#### 三、3D基础几何体（基元）
提供三种基础体，拖拽或参数生成均可。这三种基元在数据结构、材质赋予、后续布尔运算参与度上与"由2D生成的3D体"**完全等价**，仅是生成入口不同。

- **长方体**
- **球体**
- **甜甜圈形**

#### 四、3D生成工具（由2D草图进阶）
以下三种工具均需提供**一个布尔选项开关**，让用户选择生成过程中的重叠处理模式（详见统一规则）。

1. **拉伸**：选中一个2D面，沿其**平面法向**拉伸给定高度，生成实体。
2. **路径扫描**：选中一个2D面 + 任意空间曲线。扫描时采用 **Frenet-Serret 框架**（截面始终垂直于路径切线方向），路径起点无需与截面相交。
3. **旋转体**：选中一个2D面 + 一根旋转轴 + 旋转角度。

**3D生成工具的统一重叠处理规则（适用于本节拉伸/扫描/旋转）：**
- **默认模式（禁止自动布尔减）** ：生成过程中，若实体在空间发生自身重叠，**重叠部分保留且重复累加**（即覆盖两次仍是实体，覆盖三次仍是实体）。
- **可选模式（启用自动布尔减）** ：当用户打开"自动布尔减"开关后，重叠区域按照 **"奇偶规则"** 切换实体/空洞状态：
  - 第1次覆盖 → **实体**
  - 第2次覆盖 → **空洞**（被减掉）
  - 第3次覆盖 → **实体**（重新覆盖上）
  - 第4次覆盖 → **空洞**（以此类推，奇数为实体，偶数为空洞）
- 该开关对拉伸、扫描、旋转三种工具**统一生效**（可在全局设置面板中提供，也可在每个工具的参数面板中独立提供）。

4. **抽壳**：选中一个3D体，输入厚度值，生成仅保留外表皮且带有均匀厚度的空心壳体。

#### 五、2D面的核心拓扑逻辑（自动分割）
系统**严禁**采用"绘制即面"逻辑。面域生成遵循 **"仅识别由已绘制线段围成的有界闭合区域"** 。
- 当新线条与已有线条**相交**时，系统需**自动计算并分割**原有的闭合区域，生成多个独立的面对象。
- **举例验证**：绘制一个正方形，再以正方形一个顶点为圆心、边长为半径画圆（弧线穿过正方形相邻两边）。此时，系统必须自动分割出 **3个独立可点选的面对象**：①1/4圆扇形；②正方形剩余部分；③圆在正方形外部的3/4剩余部分。
- **边界规则**：单独的圆仅产生内部一个面；无穷远区域、未围合区域不生成面，不可选。

#### 六、选中物体后的变换交互（Gizmo）
选中一个物体（2D面或3D体）后，必须显示可拖拽的操作柄：
1. **平移**：显示 **X、Y、Z 轴向箭头**，拖拽箭头使物体沿该轴移动。
2. **旋转**：显示 **三轴旋转把柄**。旋转计算采用 **局部欧拉角**，且把柄的轴向**必须实时跟随物体的自身旋转**。即物体旋转后再次被选中，Gizmo朝向须与物体局部坐标系对齐，而非固定在世界坐标轴。

#### 七、高级编辑与材质系统
1. **布尔运算**：允许对两个**已有的、独立的**3D体进行 **并集** 与 **交集** 操作。（此处的布尔运算是独立的显式操作，与第四节生成工具中的"自动布尔减开关"无关。）
2. **合并分组**：允许将多个3D体合并为一个逻辑组，组内任一物体被选中，组内所有物体高亮联动。
3. **材质编辑器**：可修改物体的**颜色**与**透明度**。预设材质模板必须包含：
   - 初始材料（哑光塑料/尼龙，无高光）
   - 金属（高光、反射光泽）
   - 玻璃（透明、菲涅尔效应）
   - 木材（粗糙、漫反射）
   渲染效果需使用光照模型进行区分。

#### 八、其他基础工具
- **选择工具**：支持**拖拽框选**（矩形选框）多个物体。


#### 九、渲染性能要求

建模工具作为交互式图形应用，渲染性能直接影响用户体验与可用性。系统须满足以下性能指标：

**1. 帧率要求**
- 在符合最低硬件配置标准的设备上，交互操作（视角旋转、平移、缩放、物体拖拽变换）过程中的渲染帧率应**稳定不低于 30 FPS**。
- 理想情况下，在推荐配置设备上应达到 **60 FPS** 的流畅交互标准。
- 单帧渲染耗时不应超过 33ms（对应30 FPS）。

**2. 场景复杂度基准**
- 系统应能流畅处理**包含不少于 50 个独立3D实体**的场景（每个实体为中等复杂度网格，如拉伸体约含数百至数千个三角面）。
- 2D草图区域应能处理**不少于 100 条独立线段/曲线**的相交与分割计算，且计算耗时不超过 500ms。

**3. 最低硬件配置参考标准**
参照主流3D建模软件（如Blender、Fusion 360、SolidWorks）的系统要求：

- **CPU**：4 核或以上，支持 64 位架构
- **内存**：最低 8 GB，推荐 16-32 GB
- **GPU**：支持 OpenGL 4.3 或 DirectX 11 以上，具备 2 GB 以上显存
- **磁盘**：安装与缓存空间充足（参考标准为 8-30 GB）

**4. 性能优化要求**
- 系统应具备**视图裁剪（View Frustum Culling）** 机制，不渲染视口之外的物体。
- 对于复杂模型，建议实现**细节层次（LOD）** 或**几何简化**策略，在保证视觉效果的前提下控制三角面数量。
- 材质切换与参数修改应做到**实时响应**，延迟不超过 100ms。

**5. 性能验证方式**
交付物中应包含**性能自测说明**，记录在目标硬件上运行时的帧率表现与场景承载能力。评审时将根据实际运行表现进行验证。
