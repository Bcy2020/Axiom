# 重建：功能/行为级特性清单（来自功能块图，PRD 盲重建）

本文档仅依据分解产物（功能块图）**重述该系统实现的能力与特性**，以产品需求口吻（"系统应支持/应满足"）描述**用户能做什么、系统做什么**。不描述块树结构，不引用任何 PRD 原文。

> 说明：本重建将约束、性能/规模基线、最低硬件绑定、材质模板区分属性、拓扑边界规则等全部按原文捕获；标注"建议"的为推荐项，其余为强制项。

---

## 一、整体系统特性（主应用）

1. **系统应提供一个 3D 建模主应用**，作为统一入口：接管用户交互，协调各功能模块，并输出视口画面与导出/导入文件。

### 约束（强制执行，禁止的实现方式）
- **系统严禁使用任何提供完整 B-rep 建模能力或"一键式 3D 编辑器全流程"的现成 SDK**（此为 out_of_scope 边界条件）。
- **系统允许适当选用外部库辅助"非核心"业务逻辑**（如数学计算 / 几何相交判定 / UI 组件）；**核心建模逻辑必须自研**。

---

## 二、功能区域与能力清单（每个能力对应一个用户可发起的行为）

### 区域 1：视口与相机控制
- **系统应支持视口三维视角旋转**：用户通过右键拖拽旋转三维视角。
- **系统应支持视口平移**：用户通过中键拖拽平移视角。
- **系统应支持切换俯视正交投影模式**：俯视正交即"草图模式"，2D 几何落于 Z=0 平面。
  - **系统不应另设独立的 2D 界面区**：退出俯视正交即进入 3D 观察/编辑模式（俯视正交与草图模式为同一视图）。
- **系统应支持自适应网格与网格吸附**：提供自适应网格，并在绘制/位移时启用网格吸附。

### 区域 2：2D 草图工具集
- **系统应支持绘制线段**：提供"自由两点"或"参数：起点 + 长度"两种方式。
- **系统应支持绘制圆形**：提供"自由圆心 + 圆上点"或"参数：圆心 + 半径"两种方式。
- **系统应支持绘制贝塞尔曲线**：仅自由绘制，支持多点。
- **系统应支持绘制正多边形**：提供"自由一条边 + 边数"或"参数：中心 + 边长 + 边数"两种方式。
- **系统应支持绘制椭圆**：提供"自由两焦点 + 圆上点"或"参数：两焦点 + 离心率"两种方式。

### 区域 3：2D 面自动分割拓扑
- **系统应仅识别有界闭合区域并生成面**。
  - **系统应在新线条相交时自动分割原有的闭合区域**，生成相互独立、可单独点选的面对象。
  - **单独的圆仅产生其内部的一个面**。
  - **系统不应为无穷远或未围合（open）的区域生成面**。

### 区域 4：3D 基础几何体（基元）
- **系统应支持创建长方体基元**。
- **系统应支持创建球体基元**。
- **系统应支持创建甜甜圈形（圆环）基元**。
  - **上述三种基元在数据结构、材质、布尔参与度上与由 2D 面生成的 3D 实体完全等价**。

### 区域 5：3D 生成工具集
- **系统应支持拉伸（Extrude）生成实体**：选中 2D 面，沿其平面法向拉伸给定高度，生成实体。
- **系统应支持扫描（Sweep）生成实体**：选中 2D 面 + 任意空间曲线，沿路径按 Frenet-Serret 扫描生成实体。
  - 截面应始终垂直于路径切线。
  - 路径起点无需与截面相交。
- **系统应支持旋转（Revolve）生成旋转体**：选中 2D 面 + 旋转轴 + 旋转角度，生成旋转体。
- **系统应支持抽壳（Shell）**：选中 3D 实体，输入厚度，生成均匀厚度的空心壳体。
- **系统应支持统一的重叠处理规则（奇偶规则）**：
  - **规则默认关闭**：重叠保留并累加（覆盖两次仍是实体）。
  - **规则开启"自动布尔减"后**：按奇偶规则切换实体/空洞状态（第 1 次=实体，第 2 次=空洞，第 3 次=实体……奇=实体，偶=空洞）。
  - **该开关对拉伸、扫描、旋转统一生效**。

### 区域 6：Gizmo 变换
- **系统应支持平移变换**：显示 X/Y/Z 轴向箭头，用户拖拽箭头使物体沿对应轴平移。
- **系统应支持旋转变换**：显示三轴旋转把柄，旋转采用**局部欧拉角**。
  - 把柄轴向应实时跟随物体自身旋转（与物体本地坐标对齐），**而非固定的世界轴**。

### 区域 7：高级编辑与材质
- **系统应支持对两个已有独立 3D 实体执行布尔运算**：提供并集/交集。
  - 此为独立显式操作，**与自动布尔减开关无关**。
- **系统应支持多实体成组**：将多个 3D 实体合并为逻辑组；组内任一被选中，则全部高亮联动。
- **系统应支持编辑材质**：修改颜色/透明度，并选用预设材质模板；渲染采用光照模型对各模板加以区分。
  - **初始材质模板及其区分属性**：
    - **哑光塑料**：无高光。
    - **金属**：高光反射光泽。
    - **玻璃**：透明 + 菲涅尔效应。
    - **木材**：粗糙漫反射。
  - 材质切换与参数修改须**实时响应（<100ms）**。

### 区域 8：选择工具
- **系统应支持拖拽矩形框选多个物体**：可同时框选 2D 面或 3D 实体。

### 区域 9：渲染管线
- **系统应支持视口渲染**。
- **系统应执行视锥裁剪**：不渲染视口外的物体。
- **系统应支持 LOD / 几何简化**（**建议项**，非强制）。
- **系统应支持光照/材质渲染**。

### 区域 10：导出 / 导入持久化
- **系统应支持导出场景**：将场景全部模型数据（几何 / 材质 / 变换 / 分组层级）导出为文件。
- **系统应支持导入场景**：从文件重新导入，恢复完整场景。

## 三、全局数据来源与去向（状态源）
系统管理与读写以下数据：
- **场景模型数据**（3D 实体 / 2D 面 / 变换 / 分组 / 材质绑定）。
- **2D 草图几何**（线段 / 圆 / 贝塞尔 / 正多边形 / 椭圆）。
- **2D 面自动分割拓扑**（闭合区域 / 相交分割 / 有界区域）。
- **预设材质模板库**（塑料 / 金属 / 玻璃 / 木材）。
- **视口 / 相机状态**（相机 / 视图模式 / 网格 / 吸附设置）。
- **场景文件**（导出 / 导入）。

---

## 四、性能 / 规模基线（按原文捕获）

- **2D 面自动分割拓扑**：**≥100 条独立线段/曲线**的相交与分割计算耗时 **≤500ms**。
- **渲染管线**（在符合最低硬件配置标准的设备上）：
  - 交互渲染帧率 **≥30FPS**（理想 60FPS，单帧 **≤33ms**）。
  - 流畅处理 **≥50 个独立 3D 实体场景**。
- **材质实时响应**：材质切换与参数修改**实时响应（<100ms）**。

---

## 五、绑定前置条件（最低硬件）

- 渲染管线的帧率与流畅度保证以**符合最低硬件配置标准的设备**为绑定前置条件；其上的交互渲染帧率 **≥30FPS**（理想 60FPS，单帧 ≤33ms）。

---

## 六、"建议/推荐" vs 强制（按原文框架）

- **推荐项**：LOD / 几何简化（渲染管线中标注为"建议"）。
- **强制项**：除上述"建议"外，本文档所有能力与性能/规模基线均为强制要求，包括：2D 拓扑 ≥100 条 ≤500ms、渲染 ≥30FPS/理想 60FPS/单帧 ≤33ms、≥50 个独立 3D 实体、材质 <100ms、单独的圆仅产生内部一个面、禁止现成 B-rep/一键编辑器 SDK、允许外库仅限非核心逻辑且核心建模自研。
